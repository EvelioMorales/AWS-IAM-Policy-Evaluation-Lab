# Security and privacy notes

- The bucket name and object shown in this repository are fictional.
- No AWS account ID, email address, access key, secret key, session token, IAM username, or production resource is included.
- The policy was evaluated in Custom mode and was not attached to a live identity.
- Never commit AWS credentials, exported environment variables, or screenshots containing account identifiers.

If adapting this lab, replace the example ARN locally and review every screenshot before publishing it.
